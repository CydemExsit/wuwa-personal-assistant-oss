# 1.1.2 — 簡化安裝與首次使用

- 以單一 Setup.exe 為一般使用者主要入口；不需 Python、指令或管理員權限。
- 自動安裝完整程式，建立桌面／開始捷徑，支援 Windows 解除安裝；保留免安裝 ZIP。
- 快速開始由三頁縮成一頁，依顯示器配置預選模式、支援螢幕與解析度。
- 螢幕測試仍需明確點擊；不自動擷取、不改遊戲或系統設定，錯誤與未知資料保留保護。
- 兩版安裝目錄與捷徑各自獨立，既有本機資料位置沿用；更新／解除安裝保留資料。
- 建置／CI 驗證安裝檔、捷徑、安裝內容、重裝、解除安裝與資料保留，附驗證報告及 SHA-256。

封裝未簽章，Windows 可能顯示 SmartScreen；1080p OCR 原生環境覆蓋仍有限。
安裝來源為此 repository 的正式 GitHub Release，請勿停用 Windows 安全功能。
