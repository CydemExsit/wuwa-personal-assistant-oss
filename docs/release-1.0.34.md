# v1.0.34 — 聲骸分數連續漸層

每個已評分的聲骸使用共用連續色帶，從低分紅橘色經黃、黃綠、綠、青藍，逐漸轉為高分紫色。中間分數也有明確顏色，相近分數細微變化；五件總分以總分除以5換算，相同平均分與單件分數對應同色。

範圍包含角色總分卡、五件位置分數、低分單件、配裝詳情及位置選擇、角色配裝卡與均分、即時累積分、完成期望與範圍端點、現有目標分、評分預覽及歷史列表。多個預估值在同一行時，數字各自著色。零分使用低分色；資料不足、待評分使用中性灰色。數字保持透明背景，切換、更新和清除資料時同步更新顏色。

顏色表示數值高低；角色及格門檻、套裝與主詞條適配仍看原有文字及建議。得分公式、權重、決策政策及保存資料不變。副詞條貢獻、分差和機率保留原本表示方式，避免混用整顆聲骸的百分制色帶。

成品：`dist/releases/1.0.34/WuwaPersonalAssistant/WuwaPersonalAssistant.exe`。關閉舊版後啟動，保留同層 `_internal` 資料夾。

## 驗證

- 漸層涵蓋0–100及小數、500分換算、空值、數值夾限、各頁相同數值一致、重評／切換／清除及字型保留。
- 整條色帶在一般與選取卡片背景的文字對比均至少4.5；實際 Qt 前景與透明背景另外驗證。
- 原始資料庫只讀，使用副本檢查 Windows Qt 125%／200% 的總覽、低分單件、配裝詳情、角色摘要與配裝卡；即時、預覽和歷史頁另以明確標示的合成數值覆蓋色彩範圍。每種縮放7個狀態，共檢查242個完整可見標籤；選取歷史列的實際像素保留分數顏色。擷取未啟動，原始資料庫內容指紋一致，副本完整性與外鍵正常。
