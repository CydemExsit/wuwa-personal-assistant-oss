# v1.0.20 — 自訂應用程式圖示

應用程式圖示改用使用者提供的「水晶星環中的琥珀少女」圖片。保留原圖比例與構圖，轉為包含16、24、32、48、64、128及256像素的Windows ICO，適用於不同顯示尺寸。

Windows執行檔內嵌新圖示，Qt視窗與工作列使用相同資源；原始碼啟動、Python套件與Windows封裝均包含圖示。

現有20位角色等級依使用者指定於本機資料中設為90，並各建立一筆「未指定武器」、等級90。武器名稱與類型可於角色編輯頁補上；諧振階級暫用表單預設值1，備註標明尚未確認。變更前保留SQLite備份，後續手動編輯仍可修改等級。

## 驗證

啟動檢查確認Qt能載入圖示全部七種尺寸；Windows封裝檢查確認包含圖示資源，並執行啟動與離線OCR自測。執行檔內嵌圖示與Qt資源逐一比對，避免封裝使用舊圖示。
