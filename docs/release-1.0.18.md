# v1.0.18 — 欄位覆核、穩定評分與角色養成

聲骸名稱含英數字（例如岩蛛S4型）原本會被名稱解析拒絕；整筆待確認狀態又將所有副詞條的評分信心降為0，導致數值完整卻沒有分數。現在接受有明確字母編號的名稱，保留每項原始信心，並將整件評分與分項檢查分開。

- 聲骸強化頁以顏色、欄位名稱、原因標記缺值、低信心、無效檔位或重複詞條；修正視窗優先選取問題欄位。數值正確時可直接確認該欄位，不會一併解除其他欄位的覆核。
- 原始辨識資料與信心不變；人工確認另有逐欄紀錄。欄位數量不足或畫面有問題時，明示需要重新辨識。
- 自動模式保留上次完整聲骸與分析，顯示背景更新提示；新資料與評分同時發布。等待時暫停會修改聲骸的操作，避免把舊畫面操作套在新聲骸。過期計算不覆蓋新結果，錯誤會顯示原因。
- 新增「心」的導電輸出參考、銜夢照世之心5件套與官方離線頭像。截圖是預設推薦，未提供的使用率保持缺失；攻略提供暴傷／攻擊主詞條備選與120%效率參考。
- 角色養成頁把等級、武器、五項技能集中在前方，儲存按鈕固定可見；可填入90級或將目前技能填至自己的目標，按儲存後才寫入。武器名稱、等級、諧振階級及技能目標均可手動調整。
- 移除頁面上的綜合完成度，保留聲骸分數、各項進度及未完成篩選。已有歷史資料不刪除。
- 抽卡頁增加捲動及欄位最小高度，避免小視窗或縮放時欄位互相重疊；規劃規則維持原有功能。

本版先完善手動養成輸入；角色、武器與技能的畫面辨識留待取得對應畫面後再規劃。OCR仍只在本機處理聲骸清單，不操作遊戲。
