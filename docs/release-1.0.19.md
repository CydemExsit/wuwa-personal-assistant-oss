# v1.0.19 — 精簡說明與弱目標品質檢查

角色養成頁的未評分原因原本把完整計算備註直接塞入卡片，會撐大內容並向右溢出。現在只顯示短狀態，按「查看未評分原因」或「查看評分說明」才開啟完整內容；配裝分析的條件與判斷理由也改為點開詳情。長字串會換行，內容可捲動，原始辨識信心與逐欄確認方式保留。

聲骸強化的普通提示只列出少量待確認欄位及總數，完整原因仍可在欄位標記與修正視窗查看。角色養成的下一步摘要不再列出整段評分假設。

強化建議同時考慮替換收益與候選品質：從 +15 起，若現有與候選都低於設定檔「可用」門檻，會額外檢查升滿達可用分的機率，門檻隨下一節點材料成本和胚子供給調整。候選目前超過很差的目標，也不代表值得繼續投入。未滿三條詞條仍保留前期探索；充分潛力的胚子不必先達及格，已滿級聲骸仍可正常比較替換。

使用者案例中，+22候選累積14.93、完成期望23.84，雖有33.33%機率超過25.04分的現有裝備，但達可用55分的機率只有0.67%，現在建議停止追加材料。詳細規則見[評分方法](scoring-methodology.md#13-v1019-弱目標的品質檢查)。v5是工具策略，既有評分公式、角色權重與歷史政策均保留。
