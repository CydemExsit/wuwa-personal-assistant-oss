# 角色聲骸評分與來源（v1.0.16）

## 分數代表什麼

這是**副詞條對角色參考需求的品質分**，不是傷害模擬、角色強度或投入素材後的提升量。
v1.0.8 的角色總覽用同一套通用輸出權重，並未讀取角色攻略；例如莫寧的防禦與效率需求
就不能用通用雙暴分數充分表達。原本的低分排序不應直接當作養成結論。

v1.0.9 保留公式與通用比較模式，預設改為依角色選擇參考設定：

1. 使用者在角色編輯區明確指定的設定檔優先，包括依遊戲內推薦建立的個人權重。
2. 未指定時，以角色名稱／已收錄別名配對以下九份需求參考；分隔點正規化不會把秧秧與秧秧·玄翎合併。
3. 未知角色沒有分數，要求選擇適合的設定檔，不假定所有角色都需要輸出詞條。

角色總覽及「依所屬角色需求」即時模式使用相同解析與計分。即時模式依已登記的裝備角色，
其次為使用者指定的本次目標角色，不以模糊 OCR 字串猜測。手動指定的本次評分設定仍可使用。
角色總覽可以切回固定同一設定檔比較；該模式不套每個角色的面板調整。

## 公式與重要程度

每個已辨識副詞條的品質為 `0.55 + 0.45 × (數值 − 該詞條最低值) / (最高值 − 最低值)`。
乘以該角色對此詞條的權重後加總，依官方調諧機率推算的隨機五詞條品質 P99 對應90分；其上至理論頂值保留90–100分區間。
這是高品質參考線，不要求五條頂值；分數本身不是百分位或官方傷害公式。
既有 v1 自訂設定仍以最高五項權重的總和作分母，保留原行為。
五個欄位未開齊時仍用五欄基準，另顯示已開詞條品質；+15 與 +25 不能只看累積分。
缺漏、低可信度或數值不合法的觀察不當成 0 分；總覽完整五件才算總分。

攻略通常只提供優先順序，沒有可直接採用的精確邊際收益。工具綜合攻略與遊戲內使用率，
採用 `1、0.8、0.6、0.4、0.25、0.15` 等優先級，同級相同；未列出者為 0。
調整某個詞條不代表後續詞條必須跟著升級，例如愛彌斯的固定攻擊仍保留 0.25。
**這些數字及分數門檻是專案估值，不是作者或官方提供的傷害係數。**
0 代表這份參考不加分，不代表該詞條絕對無用。不同角色相同的 70 分也不等於相同戰力。
v1.0.11 的系統模板因計分基準升版；其他七位角色權重不變，既有使用者設定保持原狀。
v1.0.16 九份角色參考升至設定版本 3：調整莫寧、愛彌斯，新增千咲；其餘六位保留原權重。
逐角色情境、調整理由及 18 篇來源見 [本次校準](release-1.0.16.md)。系統設定 ID 保留，自訂副本與歷史決策不改寫。

## 共鳴效率

角色編輯區可輸入目前**完整配裝的面板共鳴效率**，不可填單件副詞條加成。
未知時顯示「暫估」，採達標前權重，沒有假裝已達成循環要求。
若達到攻略參考（或使用者覆寫的目標），效率的額外權重上限降為 0.1，並按有效權重重新正規化。
這是避免無限獎勵溢出效率的簡化政策，不是遊戲的真實收益曲線。
共鳴效率參考取決於武器、隊伍與操作；目標達到不保證每種循環都成立。
更換裝備後請更新面板。工具不把五件副詞條相加猜成完整角色面板。
達標後的低效率權重只代表目前面板下的額外收益，不表示維持循環所需的既有充能可以直接移除。

已複製或自行編輯的設定檔完全依使用者設定，不自動改寫它的權重。
若要依遊戲內推薦調整：到「評分設定」複製最接近的設定，修改各詞條權重與說明中的來源，
再於角色選用。面板與效率目標存於既有角色養成資料，不改資料庫結構。

## 仍需另外判斷

v1.0.10 於 **2026-09-23** 重新查核八篇所選攻略的主用／備用裝備配置，保存配裝快照校驗值，
按 COST 判斷可選主詞條（固定攻擊／生命行不參與），按推薦套裝判斷方向。
與攻略不同的裝備標示「與所選攻略不同」，不宣稱所有其他玩法都不可用。
自訂養成條件及綁定同一件聲骸的人工覆寫優先。整套另檢查套裝件數：一般五件套不能混搭兩種備選；
千咲使用命理 3 件＋沉日 2 件或幽夜 2 件，沉日 1 件＋幽夜 1 件不算完成。
這些判定不額外加減副詞條分數。

「配裝分析」逐條顯示原始副詞條值、數值檔位、權重及正規化得分；顯示得分加總為單件分數。
低信心或不完整資料仍可閱讀已保存詞條，整件得分留空而非零分；v1.0.18 保留可確認詞條的分項貢獻，並列出阻擋整件評分的確切欄位。共鳴效率條件集中顯示，不重複加上暫估標籤。
從位置建立替換目標後，強化比較重新讀取角色目前的設定及裝備，避免沿用已過期的基準。
比較為唯讀預覽，不將目標角色的分數寫入其他角色的聲骸，也不自動換裝；原始辨識照常保存。
同一聲骸先前可信的套裝辨識可供強化頁沿用；跨聲骸不借用。COST 不同、拆掉完整套裝組合、
主詞條方向不合或資料不足時，不因分數較高就建議直接替換。早期建議以 +15 觀察三條詞條，
再依超越現有裝備的機率、分差與後續成本判斷；+25 顯示實際分差，詳見 [v1.0.14](release-1.0.14.md)。
比較沿用已填的現有面板效率，換裝後需更新；不模擬新舊裝備對完整面板的連鎖影響。

武器、共鳴鏈、動態增益、雙暴溢出、敵人、隊伍總傷害和每份素材的收益未被模擬。
不要只因輔助角色的個人詞條分低，就斷言她應優先於主輸出花資源。
