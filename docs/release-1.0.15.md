# v1.0.15 — 手動辨識與夢魘聲骸修正

聲骸強化頁上方新增「自動辨識／手動辨識」切換。自動模式持續觀察所選螢幕；手動模式按「辨識目前畫面」才讀取一次聲骸清單，完成後保留結果並停止擷取，換好下一顆再按一次。同一輪可以包含頁面判斷與兩次文字確認，避免把轉場混合內容當成新聲骸；待命期間不擷取畫面，也不排入 OCR 工作。

手動辨識最多等待30秒；未取得穩定結果或不在聲骸清單時會返回待命，顯示再次操作方式。逾時當下已進入原生 OCR 的呼叫會自行結束，遲到結果不會保存。停止或切換模式會清除待辦辨識並等候工作結束，切換本身不啟動另一種模式。初次使用預設仍為自動模式。

夢魘模型的金色動畫有時連到卡片選取框，造成原先的整體輪廓偵測失效、反覆取消辨識。現在會檢查格子內四邊框線及對比，保留選取位置、圖案、淘汰標記與裝備位置的變化檢查；有多個框或證據不足時仍不猜測。另修正停止時的執行緒互相等待，重啟後也會拒絕上一輪尚在介面佇列中的結果。

名稱解析會組合標題內相鄰的「夢魘」與名稱片段；偵測到左側文字可能漏讀時，會在同一張標題裁切中重讀一次。對已觀察到的「夢魔·」誤讀修正為「夢魘·」，保留原始 OCR 與信心值。沒有前綴證據的普通聲骸不會被自動改成夢魘，互相衝突的名稱會保留待確認。

千咲目前只有角色名稱資料，尚無已查核的評分設定。這種情況會直接顯示「此角色尚未設定評分需求」，可在角色頁指定自訂設定檔；辨識成功不代表已有適合該角色的詞條權重。此次未更改評分公式或自行套用其他角色權重，也未合併歷史中無法確認為同一顆的聲骸。

新版位置：`dist/releases/1.0.15/WuwaPersonalAssistant/WuwaPersonalAssistant.exe`。關閉舊版後啟動此檔，保留旁邊的 `_internal`。仍使用原本的本機資料，舊版與原捷徑保留。

驗證涵蓋手動待命無擷取、重複按鈕、逾時與遲到結果、模式切換、停止與重啟、慢速 OCR 期間選取框連到動畫、名稱片段與衝突。實際圖片驗證只使用使用者提供的本機截圖與合成動畫，並非新擷取的遊戲實況；私人樣本與本機資料不會提交至 GitHub。
