## 今日規劃

- 固定並列技能待升級清單與無音區推薦；沿用角色頁技能現況／目標，不需要輸入素材庫存。
- 每個無音區合計兩種套裝的需求。同一角色不因出現在多隊重複計入，混搭依所需件數辨識缺口。
- 主輸出持續改善但邊際順位下降；副輸出達及格後大幅降權；治療重視套裝、主詞條與必要共鳴效率，功能達標後不追副詞條高分。
- 不把未知數值當零分，不把尚未強化完整的累積低分直接當換件理由，COST 4 缺口另列實際來源提醒。
- 排序點是可解釋的規劃啟發式，不是掉率、實際傷害增幅或期望波片收益。原有聲骸評分公式不變。
- 加倍活動獨立呈現，沒有技能／聲骸缺口也可看見；不猜測遊戲內已使用次數。
