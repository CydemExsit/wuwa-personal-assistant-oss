# v1.0.10 — 離線配裝分析與替換目標

- 角色與低分單件可直接開啟配裝分析，列出五個位置的完整主副詞條、數值檔位、角色需求權重與逐條得分。
- 顯示套裝件數、目前最弱位置、補資料／繼續強化／尋找替換等下一步；資料不完整不算零分。
- 八名角色使用已查核攻略的屬性、定位、套裝及主詞條方向；自訂判定保留在進階編輯，無須每件重複確認。
- 減少總覽的暫估及待設定文字，效率條件與來源集中於配裝分析及攻略說明。
- 一鍵將角色位置帶入聲骸強化，顯示現有基準及建議詞條，新件以同一角色需求比較。比較不自動啟動擷取或重新登記裝備。
- 檢查 COST、主詞條、拆套、資料完整性和強化節點；滿級新件直接顯示分差，尚未滿級不只看低累積分。替換用途以現有裝備為基準，可改善低分裝備時，不會只因未達通用及格分就要求放棄。

配裝事實查核於 2026-09-23；八名角色的副詞條權重沿用 v1.0.9，沒有新增官方傷害公式或玩家使用率聲稱。
來源、公式與限制見 [角色評分說明](character-scoring-sources.md)。
