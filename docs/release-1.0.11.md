# v1.0.11 — 調諧機率、穗穗參考與精簡強化頁

## 日常使用

- 聲骸強化頁保留開始、停止與辨識狀態；螢幕/角色/評分設定可展開。替換目標固定在上方，需求詳情可展開，副詞條與建議並列；整理與歷史紀錄預設收合。
- 每條副詞條直接顯示得分，提示可查看角色權重與辨識信心。主詞條兩行、五個副詞條與目標可同時查看。
- 進出強化頁時獨立觀察頁首，再交由原本穩定判定與單一OCR worker分類，避免舊版面動畫令辨識停滯。暫時未知/低信心/位置不明的畫面會間隔重試。
- 角色名可確認而位置不明時，畫面明確顯示已登記、位置待確認；可點遊戲左側已裝備圓格再掃描，或展開本機位置調整。
- 完整+25數值、同角色、同套裝都符合既有紀錄時，重掃可沿用唯一已確認的位置。不同數值/套裝、未滿詞條、衝突位置及人工設定不被猜測或覆蓋；原掃描與事件不刪除。

## 評分

只有穗穗的角色需求順序更新：依使用者手動提供的遊戲內推薦，納入效率、生命%、暴傷、暴擊及固定生命，保留使用率與來源說明。百分率不是收益權重或抽取機率。其他七名角色需求權重不變。

新預設的數值機率採[庫洛官方調諧公示](https://sdk-global.kurogames.com/pro/agreement/common/language_ko/product_info)，查核2026-09-23。種類等機率、不重複，數值按各檔公示機率，取代每檔等機率的假設。

實用分以同角色隨機五詞條品質P99對應90分，90–100保留至理論最佳值的提升空間。分數不是百分位或官方傷害公式；逐條得分按加權點數分攤，可加總解釋。只算副詞條，套裝與主詞條仍另列。舊自訂設定檔和歷史決策保留原版本，不覆寫使用者權重。
