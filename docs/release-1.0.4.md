# V1.0.4 評分校準與可讀性

V1.0.4 依實際強化紀錄重新校準通用輸出型評分，並把原本容易誤解的單一「目前分數」
拆成不同用途的指標。這次調整不是替所有聲骸加固定分數：高 Roll 核心詞條在前期會獲得
合理的繼續機會，弱詞條組合及後續歪掉的聲骸仍會建議停止。

## 畫面現在顯示什麼

- **已開詞條品質**：只比較目前已解鎖的副詞條與同數量最佳副詞條，方便判斷這一階段
  的 Roll 與詞條品質。
- **副詞條累積分**：仍以 +25 的五條理想副詞條為 100 分，適合比較已經完成的聲骸；
  在 +5／+10 時偏低是預期行為。
- **預估完成分數**：顯示剩餘合法詞條與 Roll 的均勻 fallback 枚舉期望值及範圍。
- **評分依據**：沒有角色專用設定時明確顯示「通用參考」，不再把通用估算寫成角色定論。

這三個分數都只評估**副詞條**。套裝、COST、第一主屬性與固定主屬性是否適合角色，
仍是獨立的養成有效性條件，不會暗中混入分數而破壞歷史可比性。

## 通用輸出型 V2

內建「通用輸出型」模板維持穩定 ID，版本由 1 升至 2：

- 可用／及格／完美／極品門檻調整為 `50／65／85／93`；
- 普攻、重擊、共鳴技能及共鳴解放傷害加成的通用基礎權重由 `0.38` 調整為 `0.55`；
- 角色明確使用某種輸出方式時，該詞條的條件倍率由 `2.20` 調整為 `1.50`，因此角色化
  的有效權重約維持原尺度，不會重複膨脹；
- 暴擊、暴擊傷害、攻擊百分比、共鳴效率及 Roll 表維持原公式。

系統模板的來源仍是 `project_default`、`is_official=false`。它不是官方數值、Tier List 或
完整傷害模擬；使用者建立的設定檔不會被覆寫。

## 強化決策政策 V2

「繼續／停止」所用的機率門檻已移到
`src/wuwa_assistant/data/scoring/decision-policy.v2.json`，並保存資料版本與非官方來源狀態。
Breadth-first 模式會優先協助帳號補齊可用裝備，但仍會在較後階段提高繼續成本。所有剩餘
詞條與 Roll 機率仍採明確標示的均勻 fallback，不宣稱是官方掉率。

每筆新決策會同時保存 Roll 資料版本與決策政策版本。既有決策不回寫、不重算，因此舊紀錄
仍可重現當時結果。

## 不完整結果不再製造分數

- 支援的等級只接受 `+0／+5／+10／+15／+20／+25`。
- 已辨識副詞條數必須精確等於 `等級 ÷ 5`；例如 +25 少一條時只顯示「需要人工確認」，
  不會把漏掉的已解鎖詞條誤當未來可抽欄位，也不會同時顯示「已滿級」。
- 剛切入頁面時若只讀到一個名稱殘字，且沒有等級、主屬性或副詞條，該暫態結果不會建立
  幽靈 Session 或評分。

本版不需要資料庫 migration。啟動後只會將尚未由使用者修改的內建通用模板更新到 V2；
角色資料、使用者設定檔、OCR 修正、歷史 observation 與既有決策全部保留。
