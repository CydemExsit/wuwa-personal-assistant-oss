# v1.0.21 — 改善角色頭像清晰度

角色清單原先將256×256的官方頭像直接繪製成48×48，Windows縮放後再放大顯示，容易出現鋸齒與模糊。現在依實際螢幕比例產生對應像素，例如125%使用60×60、200%使用96×96，介面仍維持原來的48×48尺寸。

縮圖先使用平滑重採樣，再繪製圓角，避免細髮與眼睛在大幅縮小時產生鋸齒。清單繪製同時啟用平滑縮放。聲骸總覽與配裝頁的頭像也依螢幕比例處理，跨螢幕移動時更新像素。

保留原有20張官方圖片、角色辨識與未知角色文字替代；沿用自訂應用程式圖示及角色、武器等級90的既有資料。

## 驗證

回歸檢查涵蓋100%、125%、150%、175%、200%與300%的實體像素及固定版面尺寸、縮放變更、未知角色替代、快取隔離與實際清單繪製的像素一致性。封裝另驗證啟動、離線OCR與程式模組、頭像及圖示資源。

63項相關介面測試及完整測試流程通過，Ruff、格式、型別、相依套件、安全掃描與差異檢查均通過。實際Qt介面以資料庫副本在125%及200%檢查20位角色；140個封裝程式模組、全部20張頭像與應用程式圖示均與來源相符。
