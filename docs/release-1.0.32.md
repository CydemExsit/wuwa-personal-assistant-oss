# v1.0.32 — 兌換碼提醒選項與完成紀錄

通知方框保留原有外觀與「查看兌換碼／知道了」，新增「本次啟動不再提醒」。按下後收起通知，本次啟動即使收到新碼也不再提醒，但清單仍持續更新。這不是永久關閉自動更新；下次啟動成功檢查來源後，暫停的未完成碼仍可提醒。

每組兌換碼新增「已完成」勾選。完成狀態保存在本機，重開程式及重新整理來源後仍會保留；已完成碼不再列在預設清單或通知數量中。勾選「顯示已完成、已失效 / 過期或來源未列出的碼」即可一起查看歷史，也可取消完成，讓仍可用的碼回到預設清單。

「已完成」是手動紀錄，不會操作遊戲或確認帳號是否兌換成功。複製不會自動勾選完成。狀態儲存失敗時會還原勾選並提示，避免看似完成卻未保存。

成品：`dist/releases/1.0.32/WuwaPersonalAssistant/WuwaPersonalAssistant.exe`，保留同層 `_internal` 資料夾，關閉舊版後啟動。
