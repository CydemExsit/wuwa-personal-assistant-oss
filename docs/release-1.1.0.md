# 雙模式獨立版 1.1.0

以原版 1.0.35 的 `f5fb549` 為基底，建立 `WuwaDisplayAssistant`。原版專案、程式及資料庫保留；此版本內的單／雙螢幕模式共用角色、聲骸、歷史與評分設定。

## 使用者可見的變更

- 首次引導和設定可選單／雙螢幕、遊戲顯示器及 1920x1080／2560x1440，選項持久保存。
- 單螢幕模式按「啟動小面板」開始連續辨識，按「結束小面板」停止。模式、顯示器或解析度改變時先結束原流程。
- 面板顯示名稱／等級、聲骸分數、替換目標分數、保存與升級建議及辨識狀態，沿用完整工具的評分結果與分數色彩。
- 資料不足時列出待確認欄位，提示回工具「修正 OCR」；修正後兩個介面同步更新。更新期間保留的舊結果明確標示。
- 離開再返回同一顆聲骸時，重新確認後恢復為目前結果，不重複儲存或評分；新辨識尚在寫入時，延遲回來的舊分數仍標為上次結果。
- 面板提供五個預設位置及 Ctrl+Shift 拖曳，自訂位置持久保存並限制在所選螢幕內。離開聲骸頁面仍持續顯示。
- 主視窗會配合可用桌面大小；較小的邏輯桌面可捲動完整工作區取得設定與操作按鈕。

## 實作與驗證範圍

小面板是本工具自己的 Qt 視窗，不附掛遊戲、不尋找遊戲視窗、不注入或模擬輸入。Windows 擷取排除只套用於工具自己的視窗並讀回確認，設定失敗會拒絕開始小面板辨識。安全掃描對這兩個模組開放最小必要例外，其他輸入、程序、hook、封包及完整畫面寫檔禁令維持。

1080p 擷取按每個 ROI 對應原生像素，再將小範圍正規化至既有辨識座標；完整畫面不另行縮放或寫檔。解析度不符或擷取途中改變時停止並釋放 frame lease。

已完成的功能驗證：

- 首次設定、舊擷取測試結果拒收、資料庫重開及單／雙模式切換保留資料。
- 兩種解析度的所有 ROI 對應、1080p 實際 runtime 路徑、啟動及途中尺寸不符時的釋放與錯誤狀態。
- 真實 SQLite 與評分服務：低信心數值先不顯示分數，人工確認後完整介面和面板取得相同分數；原始辨識與人工確認紀錄分開保存。
- Windows 原生 Qt，DPR 1.25／2.0：面板顯示與欄位排版、不啟用焦點、原生穿透、拖曳後恢復、三次啟停後擷取排除維持。使用工具自有的合成背景視窗及 Qt 測試事件，未對遊戲傳送輸入。
- 11 張本機私人樣本以 1440p 和記憶體內降至 1080p 的版本回放：頁面判定 11/11 一致；其中 10 張取得非空聲骸資料，名稱、等級、COST、主副詞條語意均一致。只寫入結構化本機驗證報告，樣本未上傳。這是既有畫面的縮放回放，不代表已測遍各電腦原生 1080p 字型及遊戲 UI 設定。
- 原版工作目錄與預設資料位置隔離；封裝不含使用者資料、私人樣本或開發環境。

支援繁體中文、1920x1080／2560x1440、無邊框且填滿所選顯示器。評分公式與現有支援頁面不變；遊戲升級／調諧後回到聲骸清單會繼續讀取。
