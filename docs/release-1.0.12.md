# v1.0.12 — 中間等級、投入成本與清單辨識

## 等級與評分

支援完整 +0 至 +25。保留畫面實際等級與主詞條數值；可開啟副詞條數是 `level // 5`：0–4 為 0 條、5–9 為 1 條、10–14 為 2 條、15–19 為 3 條、20–24 為 4 條、25 為 5 條。相同副詞條在同一區間得到相同分數及剩餘潛力。

OCR、人工修正、歷史登記、角色總覽與替換比較都使用同一規則。未讀齊已解鎖詞條時仍提示確認，避免將漏讀當成尚未開啟的潛力。+0 至 +4 顯示先到 +5 調諧的提示。

## 是否繼續投入

有替換目標時，改為計算「最終分數嚴格超越現有分數」的機率，另列完成期望及 `E[max(新分數 − 目標分數, 0)]`。後者反映失敗時可以保留原裝備；不是傷害提升，也不因平均分低於現有就一律放棄。上限無法超越時停止；成功率太低時，即使上限稍高也建議改練其他胚子。

下一節點的 EXP 成本會提高投入機率門檻。門檻是工具的節省素材策略，非官方最佳策略：沿用節點基本門檻與胚子供給等情境，再加 `0.12 × 下一節點 EXP / 63,500`，最後限制於 2%–75%。替換已知裝備時不使用「尚無裝備」的折扣；自訂分數與需求權重仍保留。

## 辨識方式

即時辨識只保存「聲骸清單／選擇」畫面。進入培養、素材選擇或其他頁面時暫停內容讀取，返回清單後重新辨識。離線診斷仍能讀取舊的培養截圖，既有歷史不刪除。

新增「立即重新辨識」：清除目前畫面的辨識快取，優先重讀新畫面；仍等待短暫穩定以避免過場誤讀。保留本次掃描紀錄和單一 OCR worker，丟棄重置前尚未交付的舊結果，不新增重複的掃描工作階段。

新版路徑：`dist/releases/1.0.12/WuwaPersonalAssistant/WuwaPersonalAssistant.exe`。請關閉舊版後啟動此檔，保留同層 `_internal`；沿用原本機資料，原捷徑不會自動更新。
