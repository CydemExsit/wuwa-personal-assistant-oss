# 角色數值與遊戲面板對照

角色頁提供非戰鬥常態的生命、攻擊、防禦、暴擊、暴傷及共鳴效率。
「全部屬性與來源明細」包含傷害／治療加成、諧度初始屬性、基礎與額外加成，以及各項來源。
修改角色／武器等級、突破或技能節點後，儲存角色會重新計算；辨識更新裝備也會重算，
並保留未儲存的編輯。

## 計算範圍與狀態

- 離線快照包含20位角色、17種武器、20套合鳴及19種首位聲骸；不代表全遊戲均已支援。
- 角色初始三圍、1–90級與突破、武器基礎／第二屬性／常駐被動、八個屬性節點分別計算。
- 固有技能與首位聲骸被動列於來源明細，依已對照案例不加入非戰鬥角色面板。
  它們可能在實戰生效，不能因此判斷暴擊或共鳴效率沒有額外加成。
- 五個位置的聲骸主要、固定次要及副詞條，以及無觸發條件的合鳴效果分別加總。
  異相外觀沿用原效果；夢魘不與普通版本混同；同套重複種類只計一件。
- 諧度破壞增幅是點數，偏諧值累積效率是百分比，各角色初始值依公開資料讀取。

目前為精度校準中的功能。完整裝備與卸裝實測案例的生命／防禦仍有1–4點差異，尚未完成通用
遊戲一致性驗收。程式保留差異，不用角色專屬補差常數或直接覆蓋計算結果掩蓋它。
算式、介面及封裝測試不能取代相同裝備與節點狀態下的實際遊戲對照。

## 算式與精度

生命／防禦 = 角色基礎 × (1 + 百分比加成 / 100) + 固定值。

攻擊 = (角色基礎攻擊 + 武器基礎攻擊) × (1 + 攻擊加成 / 100) + 固定攻擊。

雙暴與共鳴效率從5%、150%、100%起算，採百分點加算。當前實測模型對成長後的角色與
武器基礎值分別取整；生命／攻擊／防禦比例以單精度轉整數萬分位後加算；武器先成長
再轉換，其餘運算使用Decimal。整數顯示向下取整，百分比顯示一位小數。
此模型仍在校準，不是官方引擎實作聲明。

20、40、50、60、70、80級有突破前後兩種狀態，需指定突破階段。
舊資料若只有部分節點勾選，請依新的具名節點核對並儲存。全開與全未開沒有順序歧義。
十個節點依序為常態攻擊、共鳴技能、固有技能、共鳴解放、變奏技能，各兩個；
調整技能升級優先序不會改變節點順序。

## 缺漏資料與實測

未知武器、未登記位置、缺漏／低信心／不合法詞條、未校對的角色／套裝／首位聲骸，
會顯示「待補資料」，明細只列已知項目小計。非零共鳴鏈與不絕餘音五件在場層數仍需校對。
不會把未知、空白或未支援的輸入當成零加成已驗證。

實測時請固定角色與武器等級、突破、諧振、共鳴鏈、節點及五件裝備，清除臨時增益。
僅離開戰鬥不一定會清除累積效果。已明確登記的本機對照資料綁定當時輸入的指紋：
只有輸入與數值都一致才顯示已對照；已測但不同會列出遊戲／計算差異；其他配置標示尚未實測。
計算面板不會覆寫既有手動評分面板，雙暴平衡與共鳴效率溢出政策為後續工作。

## 公開來源與本機資料

數值快照位於 `src/wuwa_assistant/data/characters/panel-stats.v1.json`，各項保存來源網址、
查核／更新日期及內容雜湊，只包含數值事實與必要名稱，沒有玩家帳號、裝備紀錄或圖片。
程式執行時僅讀取封裝快照，不請求網站，也不讀取其他版本的個人資料。

- 各角色／武器／合鳴／首位聲骸的具體來源見快照；主要為[庫街區WIKI](https://wiki.kurobbs.com/)。
  WIKI為玩家共同編輯，不代表全部數值已由官方認證。
- 成長與未截位武器屬性參考[固定版公開數值資料](https://github.com/Dimbreath/WutheringData/tree/e9234ffe094b2d944d16b222d31102e8ab32d954/ConfigDB)。
- 初始百分比及諧度屬性參考[固定版BaseProperty](https://github.com/Arikatsu/WutheringWaves_Data/blob/9218d612ad815e398e064e577e42aaf878899968/BinData/property/baseproperty.json)，
  依初始三圍、元素及武器類型交叉核對。

公開突破表的四個矛盾欄位列於快照 `source_anomalies`，沒有當成角色專屬覆寫。
初始武器卡片可能已截位，例如不屈命定之冠的16.0%卡片無法直接反推成長後數值；
快照保留原始比率來源。這些公開資料交叉檢查仍需實測驗收。
