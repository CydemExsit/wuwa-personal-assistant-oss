# 1.0.27 — 夜色粉紫與並排檢視

依已確認的設計方向，以粉紫呈現七草ナズナ的主題，深紫夜色作為背景，少量冰藍用於公告連結。提高主題彩度，保留明亮房間下可辨識的文字與表面層次。

- 主背景 `#1D1628`、側欄 `#261B33`、卡片 `#2E203D`、浮起表面 `#3B294C`。
- 主要文字 `#F5EDF8`、次要文字 `#CBB7D8`、粉紫強調 `#E2A0DD`、選取底色 `#55305F`。
- 聲骸工作區寬度達 1120 邏輯像素時，左側總覽與右側明細並排，可拖曳分隔線調整比例。五個位置切換單件明細，選取狀態同步標示；窄視窗保留總覽／完整明細切換與返回。
- 總覽卡片依寬度排列，縮短重複操作按鈕；既有分數、及格判斷與僅以文字顯示評分色階的規則保持一致。
- 角色內容取消固定最大寬度，新增取自實際配裝的五件摘要，可直接進入對應聲骸。
- 技能待升級與無音區推薦保留並排，表格延伸利用視窗高度。總覽摘要增加直接入口；卡池公告減少重複框線，倒數區維持足夠高度。
- 共用內文字級調整為 15px，區分主要／次要操作，修正側欄標題換行與節點勾選背景。

原有本機資料、辨識、評分模型、角色養成與活動規則沿用。參考圖片只用於設計討論，未加入程式或版本庫。
