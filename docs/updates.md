# 程式更新

程式版本更新與「更新官方公開資料」分開。Display 使用收到的安裝檔；OSS 使用固定的公開 GitHub Release 來源。
工具開啟時才可能檢查，不會送出角色、資料庫、畫面、OCR 或帳號內容。只下載同系列、較新的正式安裝檔。
公開下載使用 HTTPS 與 GitHub Release SHA-256；草稿、測試版、錯誤系列、缺少雜湊、檔案不完整皆停止。
本機選檔由使用者確認作者來源；檔名與格式檢查不能證明來源可信，不應開啟不明來源的安裝檔。
下載可取消，失敗保留原程式；下載完成也要按「安裝並重新開啟」才開始更新。

更新前先儲存編輯中的表單。工具會完成已接受的背景保存與安全關閉，再啟動安裝程式。
安裝程式等待提出更新的程序真正退出，最長 60 秒；未退出就停止，不強制終止工具。
更新沿用目前使用者的安裝目錄與相同 AppId，不要求管理員權限；ZIP 版會轉成安裝版。
安裝成功後以原本的資料根目錄重新開啟；本機資料、備份與首次設定不刪除。
更新不承諾斷電時自動回滾；安裝錯誤可重新執行正式安裝檔修復。

維護者發布時必須附上 `WuwaPersonalAssistant-系列-X.Y.Z-Setup.exe`，並完整上傳才設為 Latest。
OSS 更新依 GitHub API 的 asset digest 驗證內容；未完成的發布不可設為 Latest。
Display 不新增公開下載庫，也不在程式內保存私人 GitHub 憑證。
每次發布都執行 installer lifecycle 與 updater parent-exit / reopen 驗證。
