# 聲骸工作流程改善（未發布）

本次更新不調整版本號、評分權重、強化門檻或無音區排序公式。

## 無音區推薦理由

養成規劃 → 無音區推薦 →「查看推薦理由與資料待確認項目」，第一層直接列出
角色、定位、位置、原因、貢獻點。同角色同位置的替代套裝合併為一列；數字為
既有 `FarmBenefit.points` 分配份額與單件折減後的合計，顯示至小數三位。
各套裝細項分別四捨五入時，手動加總可能與合計末位相差一位。
這是單項需求貢獻，無音區最終養成排序點另外含角色覆蓋、雙套裝等倍率。
優先級、倍率、來源、待確認項目與完整計算仍在第二層。

## 共用無音區庫存

「聲骸」頁上方（包含配裝詳情路由）與「聲骸強化」頁右上方都有「無音區庫存」。
點擊狀態即可切換「還有可培養／需要的已用完」，也可整批設定所有已確認無音區。
養成規劃原有列內與整批操作保留，共用同一個服務及寫入佇列。
這代表該區需要的聲骸還有沒有可培養存貨，不是單顆聲骸的數量，不會由 OCR 推測。

儲存成功後更新養成規劃順位及首頁摘要；重開程式保留，各 dataset 隔離。
儲存期間停用操作，重複點擊不會排入第二筆相反操作。儲存失敗顯示錯誤且不冒充成功；
已提交但讀回失敗時暫停舊值操作，關閉後重新開啟管理視窗以重新載入。

## 助手分頁與辨識生命週期

只有停留在助手的「聲骸強化」頁面時才執行使用者啟動的辨識。
從側邊欄、返回、程式導覽離開這一頁，立即取消新畫面擷取及待處理 OCR，
沿用非同步停止流程等待已執行中的本機呼叫安全結束、釋放資源並保存已確認歷史。
取消尚在建立中的 Capture Session，亦不會稍後在別頁啟動。
舊的排隊辨識結果不可蓋回目前狀態；小面板隨正常停止流程隱藏。
切回仍顯示停止狀態，必須再次手動開始。手動單次與自動連續模式均適用。

此處是**助手的分頁**。遊戲內離開聲骸清單、進入強化或素材選擇頁面的既有規則保持原樣。
正在執行的原生 OCR 呼叫採合作式取消，安全結束前不強制終止執行緒；停止要求不等於強制殺掉原生呼叫。

## 品質建議與戰鬥驗證

替換分析保留戰鬥驗證前的品質結論及結構化可用狀態。聲骸辨識、詞條、等級及評分依據
足以做決策時，缺少戰鬥資料仍呈現「依聲骸品質評估」的保存與升級建議。
戰鬥資料待補另列提示，完整工作區與小面板共用同一份建議。

這不代表整隊最佳配裝已驗證，不把未知戰鬥收益當成零或提升。
OCR 待覆核、決策必要詞條缺漏、COST 不同、套裝／主詞條不符、拆套等仍保留保守限制；
同件、+0～4 胚子探索、+5～24 與 +25 的既有品質策略不變。
