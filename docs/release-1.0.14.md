# v1.0.14 — 穩定副詞條得分與精簡投入建議

辨識持續運作時，同一聲骸、相同詞條及評分條件的更新會保留已完成的副詞條得分。重新辨識產生新紀錄或信心值在合格範圍內微幅變動，不會先清空數字。慢速計算只保留目前工作與最新一次後續更新；換聲骸、詞條、角色、設定或替換目標時會作廢舊結果。原始辨識紀錄與信心值照常保存，後續評分仍重新讀取資料，不永久快取角色設定。

強化分析預設保留一行建議與五項數據：累積分、完成期望、範圍、超越現有裝備的機率、目前與現有的分差。材料成本、詳細理由、通用及格／完美／極品機率與評分假設移至「展開計算理由」。沒有可比較目標時不冒填替換成功率；套裝、COST、主詞條不相容時保留檢查提示。

投入建議以目前替換目標為主。前期通常先確認三條副詞條、到 +15 再評估，因為這段成本低於最後 +20→25；有目標時同時考慮超越機率、可能提升的幅度及未來投入成本。若上限已無法超越，或提升機會／幅度太小，仍可提早停止。這是可調整的工具策略，不是官方最優解；角色權重與得分公式未更換。

細節與公式見 [評分方法](scoring-methodology.md#12-v1014-前期探索與目標差距)。資料及條件不足時仍要求確認，歷史決策保留原版本。

新版位置：`dist/releases/1.0.14/WuwaPersonalAssistant/WuwaPersonalAssistant.exe`。關閉舊版後啟動此檔，保留旁邊的 `_internal`；原捷徑不會自動更新，仍使用原本本機資料。
