# v1.0.30 — 已裝備聲骸的位置保存

修復遊戲已裝備聲骸，但助手持續更新評分、顯示「位置待確認」且無法保存的位置流程。

## 修正

- 清單不足五排時，空白格的背景動畫不再參與聲骸圖案雜湊。空白／有卡片的變化仍會中斷身分比對，保留不同選取格、不同圖案及清單重新排序的保守判定。圖案與整張卡片區域都缺少邊緣時才視為空白；被判為空白的選取格不建立身分證據。
- 「保存至角色位置」可在評分更新期間操作，保存的是畫面正在顯示的聲骸，不會被背景讀到的另一顆取代。其他需要最新辨識的動作保留原有等待流程。
- 已讀到遊戲位置、但本機手動配裝尚未替換時，顯示「已辨識位置／尚未保存位置」並預選讀到的位置。按保存後更新角色配裝，原聲骸仍保留。
- 重複辨識不再改掉尚未保存的手動位置選擇。原有手動配裝保護、OCR 信心門檻與評分公式不變；不需資料結構遷移。
