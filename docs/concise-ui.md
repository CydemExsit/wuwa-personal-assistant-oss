# 精簡介面與辨識核對

保留原有導覽與操作順序。首頁、聲骸、養成、活動、卡池、兌換碼、歷史與設定依用途保留短結論；長篇操作說明可按「使用說明」展開。角色技能、五個位置、配裝問題與資料待補仍直接顯示。字級及評分模型沒有改變。

## 聲骸核對

- 按「修正 OCR」，或雙擊主／副詞條的名稱、數值，直接開啟對應欄位。
- 待確認欄位優先列出；切換欄位保留尚未送出的輸入。每次只確認目前欄位，取消不寫入。
- 確認會保存到開啟核對視窗時檢視的那筆紀錄，期間的新掃描不會改變寫入對象。原始信心與修正紀錄保留；既有評分刷新流程重新評估。
- 辨識結果正在更新時暫停開啟核對，避免修改尚未完成的結果。

剩一、兩條且資料足以比較時，分析區顯示升滿需超過的目標分數、尚需增加的分數，或目前模型無法超越。這是副詞條品質條件，不代表傷害提升；沒有目標、同件、配裝不相容或資料不足時不顯示。主結論相同的升級建議不再重複一列。辨識按鈕維持順序，狀態放在第二列，減少窄視窗橫向溢出。

## 本機角色頭像

公開版沒有可確認允許再散布的遊戲頭像授權，因此倉庫及安裝包仍不附遊戲圖片。提供使用者自行匯入本機圖片的替代方式，預設保留文字頭像。

設定 → 一般設定 → 角色頭像，選擇角色後匯入有權使用的 PNG、JPEG 或 WebP。
圖片上限 12 MB、4096 x 4096，會以中央正方形裁切為 256 x 256，僅保存像素。
匯入後立即更新相關角色頭像；重啟保留，可按「恢復預設頭像」。

頭像獨立存於目前版本資料根目錄下的 `portraits`，不修改資料庫、不讀取另一版本的資料，也不連網。現有 SQLite／JSON 備份不包含這個資料夾，遷移時可另行複製。個人版既有內建頭像保留；沒有內建或自訂圖片時使用文字頭像。

## 驗證範圍

使用合成資料驗證核對、欄位草稿、新掃描期間的寫入對象、匯入／重啟／還原、版本目錄隔離、圖片格式／尺寸與錯誤保護。各版另執行完整品質檢查、Windows Qt DPR 1.25／2.0、寬窄視窗與封裝驗證。資料相容性使用副本，不把私人資料移到公開版。這不構成新的遊戲實況 OCR 品質或效能量測。
