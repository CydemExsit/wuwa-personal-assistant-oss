# OSS 1.1.11 — 莉莉與同奏角色支援

- 完整新增莉莉與補齊鎖暝：角色清單、基礎面板、技能節點、共鳴鏈、安魂／沉冥、合鳴與隊伍增益。
- 莉莉同奏方案採茜染懷想之花5件、首位3C解形煞與43311。4C生命%及治療效果加成都可比較與預測，3C保留效率／衍射增傷，1C生命%；副詞條效率＞生命%＞固定生命，效率260%為轉換上限參考。
- 新建莉莉採傷害優先的變奏與迴路目標10，其餘6；既有角色技能與手動設定保留。鎖暝採同奏副輸出，並支援與心、莉莉的條件增益。
- 區分重擊終結、強化變奏與聲骸技能窗口，避免指定技能雙暴變成全局加成。效率、諧振階級、同奏層數與作用對象分別核對，達標後多餘效率不增加戰鬥指標。
- 解形煞首位10%效率計入面板一次。生命與治療加成都納入莉莉綜合指標，數值不代表實際治療量或隊伍總傷害。
- 使用公開攻略與正式資料核對角色機制；創作者配裝圖與遊戲使用率分開，缺少的比例保留未知。[Kin](https://mcguide.kurogames.com/zh-Hant/?role_id=1512&strategy_id=11098)、[巡游天国FM](https://mcguide.kurogames.com/zh-Hans/?role_id=1512&strategy_id=10238)、[庫街區WIKI](https://wiki.kurobbs.com/mc/item/1559521973715369984)。來源查核2026-11-16；兩版角色與評分數值一致。
- 公開倉庫與安裝包不附遊戲圖片或私人資料，保留文字頭像及本機匯入。角色資料不代表帳號已擁有，不會建立虛構庫存或跨版本讀取資料。

此版本也包含 CHANGELOG 中1.1.5至1.1.10及Unreleased已整合的功能。依現有實測範圍使用面板與理想輪轉模型，莉莉尚無遊戲面板逐項實測資料。

相依套件沒有新增；完整第三方對應原始碼維持[1.1.2的固定來源包](https://github.com/CydemExsit/wuwa-personal-assistant-oss/releases/tag/v1.1.2)，Certifi對應來源隨本版提供。建置會重新核對來源、授權文字及CA內容。
