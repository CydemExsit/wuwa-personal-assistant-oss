# 1.1.7 已裝備聲骸自動同步修復

修復聲骸內容、角色與位置都辨識成功，工具卻仍保留舊裝備的問題。例如先手動保存
+20 聲骸，再將它強化到 +25 並回到遊戲聲骸清單，新辨識結果現在會自動套用至
角色位置，不必再按「保存至角色位置」。換裝與角色間移動也使用同一套同步規則。

即時辨識必須在聲骸清單確認「已裝備」，同一畫面的角色與明確位置皆達
`max(0.90, 使用者設定的信心門檻)`，才可更新先前手動保存的裝備。
只有角色、位置不確定、依舊紀錄推得的位置與歷史資料修復，仍保留手動設定。
替換只更新本機角色配裝，原聲骸與辨識歷史仍留在清單；不需資料結構遷移。

新版啟動後，重新辨識遊戲目前裝備即可同步。封裝須保留
`WuwaPersonalAssistant.exe` 同層的 `_internal` 資料夾。

驗證涵蓋手動位置替換、手動裝備跨角色移動、信心門檻邊界、不確定與歷史資料保護、
重複掃描、SQLite 重開、角色更新通知與辨識頁已保存狀態，並檢查完整品質與 Windows 封裝。

公開版鎖定環境同步更新至 Certifi 2026.10.19 與 Pillow 13.0.0，並更新 Certifi
對應來源與雜湊，以通過目前的依賴安全稽核。修正依據見
[Certifi 安全公告](https://github.com/advisories/GHSA-6q48-6c7w-9gw2)與
[Pillow 13.0.0 版本說明](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html)。
