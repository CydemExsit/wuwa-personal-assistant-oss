程式更新入口位於設定頁最上方。OSS 可檢查正式新版、下載並驗證 SHA-256，下載與安裝都由使用者決定。
Display 維持私人發布，朋友可直接執行收到的安裝檔，或從工具內選取；不新增公開下載庫或憑證設定。
安裝前會完成已接受的保存與安全關閉，等待原程序退出後更新，成功後以相同資料位置重新開啟。
安裝版沿用原位置；ZIP 版使用這個入口時轉為目前使用者的安裝版。角色、歷史、設定與備份保留。
舊版需先手動安裝此版一次，之後即可使用工具內入口。編輯中的表單請先儲存。

驗證包含正式版/來源/大小/雜湊/取消/錯誤/同系列本機選檔、安裝前再次比對雜湊、
Qt 非阻塞與安全關閉、Windows 原生 125%/200% 可見操作區，以及真正 Setup 等待程序退出、
重新開啟與 SQLite 邏輯內容/完整性/外鍵檢查。完整 gate 與封裝結果以同版 VerificationReports 為準。
