# 1.0.23 — 深色主題、低分單件卡片與混搭判定

## 三項需求

1. 全工具改用深灰底、淡紫粉重點色及淺色文字。一般／停用／焦點／勾選與低分／高品質色階一併調整，角色頭像清單和辨識警示也使用深色配色。
2. 低分單件取消 12 件上限，按分數由低到高顯示全部目前可評分的裝備。隨可用寬度排列成 1–4 欄卡片，保留角色、位置、頭像、分數、聲骸名稱及查看配裝功能。
3. 蕾貝卡與露西的問題來自套裝名稱一字差異，並非混搭順序。既有計數判定已忽略順序，但本機 OCR 記錄為「碎夢亡鬼之魔」，攻略名稱為「碎夢亡鬼之魘」。為這兩位角色新增精確的辨識別名對應，保留原始資料與信心值，不採模糊名稱比對。

## 套裝依據與保護

- 蕾貝卡仍要求 1 碎夢 + 2 不絕 + 2 冥雷；露西仍要求 1 碎夢 + 2 不絕 + 2 浮星。
- 攻略平台原始 API 留存資料的套裝欄位為「碎梦亡鬼之魇」，套裝 ID 32，與既有攻略對應；辨識記錄中的「魔」是相容別名。
- 兩份留存資料分別對應 [蕾貝卡攻略](https://mcguide.kurogames.com/zh-Hans/?role_id=1308&strategy_id=10187) 與 [露西攻略](https://mcguide.kurogames.com/zh-Hans/?role_id=1511&strategy_id=10188)，校驗值符合既有攻略來源記錄。
- 錯誤件數、缺少位置及未知套裝仍不會被當作套裝完成；沒有更改角色權重、評分公式或歷史 OCR 紀錄。
