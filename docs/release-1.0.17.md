## 使用

關閉舊版本，再啟動 `dist/releases/1.0.17/WuwaPersonalAssistant/WuwaPersonalAssistant.exe`，保留同資料夾的 `_internal`。既有資料沿用原本本機資料夾。新增角色尚未掃描裝備、輸入等級／武器／技能時，工具不會從推薦截圖推定這些進度或虛構聲骸分數。

驗證涵蓋十張參考的數值與缺項、19人目錄與頭像、混套完整度、角色機制差異、舊設定檔升級與自訂資料保留、封存顯示和Qt介面，以及Windows封裝的程式／資料／頭像一致性。

本機驗證2026-10-03：全套1110項＝1109通過、1項既有選擇性網路測試略過；Ruff、格式、mypy158個來源檔、依賴及安全掃描通過。實際Qt程式在資料庫副本顯示19位角色／完整來源與圖片，未啟用擷取。Windows封裝通過OCR與啟動檢查，138個內嵌程式模組、角色／評分JSON與19張頭像均與來源一致。
