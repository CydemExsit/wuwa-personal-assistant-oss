# 1.0.22 — 淡紫粉介面與角色／聲骸工作流程

## 使用方式

- 「角色」直接開啟養成查看模式，右側頭像可上下捲動或展開為三欄。
- 技能與小型屬性節點直接修改；等級、武器等資料需按「編輯角色資料」。按「儲存角色」保存。
- 「聲骸」集中顯示角色五件總分（500 分）、五個單件分數，或切換最低分單件。
- 角色總分可升冪／降冪排列及篩選養成項目；低分單件自動升冪，不套用隱藏的角色篩選。
- 配裝分析集中顯示優先詞條，可按「目前有效權重」查看條件。每件保留「以此聲骸為目標開始替換」。
- 滑鼠靠手腕的側鍵四、Alt+← 及左側返回按鈕可返回上一頁，包含替換前的配裝位置。
- 新角色依高信心裝配辨識自動登記名字；攻略與評分資料仍須另外更新。辨識更新不覆寫未儲存草稿。

## 修正與呈現

- 共用詳細說明按鈕在設定內容時可能尚無父元件；Qt 原本會顯示 122×20／86×20 的短暫頂層小窗。
  現在等到版面接管元件後才顯示，涵蓋配裝查看與辨識觸發的背景更新。
- 立即重新辨識按鈕在建立時即指定父元件，避免控制項初始化造成同型態小窗。
- 淡紫粉配色搭配深色文字、清楚的焦點與停用狀態。未達角色需求用玫瑰色，至少 90 分且無已知
  需求不符的聲骸用綠色，未知值保留中性狀態。色階不改動既有評分或合格門檻。
- 保留圖示與依 Windows 縮放比例產生的平滑角色頭像。
- 移除日常頁面的比較基準、角色搜尋、名稱排序、重複優先詞條及公式／來源按鈕。

## 資料與驗證

本版不變更資料庫結構、不改寫原始辨識或歷史分數。畫面驗證使用本機資料庫副本，原始資料庫
只讀備份，辨識保持關閉。Windows 安裝包仍為 one-folder；執行檔必須與同層 `_internal` 一起保留。

- 完整品質檢查 `scripts/test.ps1` 通過：1,212 個測試中 1,211 通過、1 個既有選用官方網路測試跳過；Ruff、306 個檔案格式、mypy 160 個來源檔、相依套件、安全掃描及 diff check 通過。
- 原生 Windows Qt 閃爍與返回導覽 11 個測試通過；測試會捕捉每次頂層 Show 事件，包含截圖來不及捕捉的瞬間視窗。
- 125%／200% 各檢查 1100×720、1200×800、1440×900，42 張實際 Qt 畫面；查看、編輯、三欄頭像、總分、低分單件、配裝及強化頁均檢查。
- 聲骸總覽上述三種尺寸分別完整顯示 6／9／12 張角色卡。角色表單與配裝頁無水平溢出。
- 使用既有 20 位角色資料驗證替換後側鍵返回原位置、自動刷新保留草稿；原始資料庫 27 張表逐列指紋不變。

## Acceptance criteria 對照

| 需求 | 實作與驗證 |
| --- | --- |
| 1. 辨識／查看配裝瞬間小窗 | 父元件建立後才顯示，啟動與可見／隱藏配裝反覆更新均無額外頂層 Show；`test_transient_windows.py`。 |
| 2. 滑鼠按鍵四返回 | 子元件、說明視窗、跨工作區與指定聲骸位置返回；`test_main_window.py` 及實際 presenter 替換流程。 |
| 3. Pale purple 主題 | 全域淡紫粉 QSS、深色文字、焦點／停用／勾選及分數色階；`test_theme.py` 與兩種縮放實際畫面。 |
| 4. 角色介面重製 | 角色直接養成、右側三欄頭像、查看／編輯、直接技能與節點、阻止滾輪誤改；角色與 presenter 回歸測試。 |
| 4. 聲骸重製 | 獨立聲骸入口、總分排序／最低單件、五件彩色分數、精簡控制項、集中優先詞條與有效權重、保留替換；overview/detail 測試與 42 張實際畫面。 |

本次未啟用使用者的即時遊戲擷取；辨識更新路徑由原生 Qt、presenter 回歸與本機資料副本驗證。
