# V1.0.6 辨識速度與角色配裝流程

## 使用方式

- 聲骸選擇頁右下角出現「角色名裝配中／裝備中」時，工具顯示明確的裝配角色名稱。
  高信心（至少 90%，且不低於使用者設定）的新名稱會加入目前資料集的本機角色庫；
  不會猜測元素、職能或遊戲內裝備位置。已封存角色不會自動恢復。
- 選好角色與位置 1–5 後，按「保留並套用位置」或「保存至角色位置」，角色頁直接同步。
  若該位置已有聲骸，舊聲骸會解除位置關聯並留在清單。單純保留已配裝的聲骸不會清除位置。
- 再次查看已保存的聲骸會顯示原本的角色與位置；重複辨識或角色庫更新不會蓋掉正在調整的選擇。
- 背景辨識刷新角色頁時保留尚未儲存的角色、武器、技能、備註與新增草稿，只同步配裝與清單。
- 角色名辨識使用完整文字與相鄰 OCR 片段，不依賴預先列出的角色名稱。
  明確文字可覆蓋錯誤的卡片徽章判斷；角色文字與按鈕直接矛盾時仍保持未知。

## 辨識調整

RapidOCR 原本會把小區域的短邊放大到 736 像素。現在僅對短邊不超過 128、長邊不超過
680 的小型文字區域保留原生尺寸；大型主副詞條區域沿用既有辨識設定與信心門檻。
裝配角色區域的穩定雜湊改用金色／白色文字前景，降低深色背景動畫造成的反覆等待。
ONNX 推論限制為最多 4 個運算執行緒，減少多模型各自使用大量 CPU 執行緒造成的競爭。
0.60 秒穩定門、選中格與卡面變更判斷、過期結果保護維持有效。

另補齊六種元素傷害加成的主詞條名稱，包含使用者截圖的「熱熔傷害加成」。
若大區域漏讀 COST 數字，僅重讀同一張畫面已裁切的 COST 行；弱信心與衝突證據仍保持未知。
保留上一版取消棄置狀態修正與 Windows 建置 PATH 隔離，避免再次包入不相容的 Qt 相依 DLL。

所有辨識在本機完成；沒有自動操作遊戲、畫面上傳或新增完整畫面保存。
