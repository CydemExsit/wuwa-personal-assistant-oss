# 1.1.6 角色面板版面調整

寬視窗將角色摘要與六項常態數值並排，數值依可用寬度排成六、三或兩欄，
來源明細、重新核對與核對明細收在同一列。技能填值與優先順序操作合併，
節點縮小多餘間距，五件聲骸摘要往上移；窄視窗自動換行，保留文字大小。

角色、武器、節點與聲骸仍使用原有即時計算與核對流程。改變視窗大小、
角色清單展開或編輯模式不會重建表單，未儲存的武器與技能編輯會保留。

驗證包含真實主視窗的可見範圍、五列技能與五件聲骸操作、窄視窗與展開清單、
Windows 125%／200% 縮放，以及完整品質與 Windows 封裝檢查。
較小或較高縮放的視窗仍可垂直捲動；編輯資料與配裝管理保持可展開。
