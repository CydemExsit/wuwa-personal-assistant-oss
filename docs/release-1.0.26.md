# 1.0.26 — 養成與活動介面調整

1. 「今日規劃」改名「養成規劃」, 移除日期選擇。技能待升級、無音區建議與兩種加倍活動倒數保留。
2. 技能移除核心勾選。較高目標預設在前; 選擇技能後使用「提前升級／延後升級」, 按「儲存角色」保留順序, 養成規劃同步使用。
3. 共鳴效率直接顯示已查核攻略建議, 移除要求手填的日常欄位與提示。未知面板不會被當成已達建議值; 現有手動資料保留。
4. 下一期喚取角色名稱修正為「鎖暝」, 依官方 5562 文字公告核對。
5. 活動以緊湊雙欄依截止時間排序; 未開始活動預設收合。團團勇者大亂鬥加入官方公告圖。海墟與深塔各自倒數、勾選本期完成, 不再用每週重置代替。
6. 週末提醒使用 HH:mm 時間選擇器, 小時與分鐘都會保存到 Windows 排程。
7. 歷史紀錄完整移至「設定 → 歷史紀錄」; 舊的歷史頁路由仍會導向此分頁。
8. 聲骸的角色總分／低分單件與升降序改為直接切換按鈕。共用控制元件也套用至其他非自由輸入的二選一選項, 清楚標示目前選擇。
