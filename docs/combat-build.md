# 戰鬥隊伍與聲骸配裝比較

從角色頁的「戰鬥隊伍」新增常用配置，選擇最多兩位隊友、主要隊伍、戰鬥充能目標及
主要輸出窗口。每位角色獨立保存，隊友可以重複出現在其他配置；所有配置共用同一套
聲骸。每支登記隊伍都是必用隊伍，只有全部充能足夠才算可直接換裝。

## 輪轉情境

模型採正常操作下可循環取得、主要輸出窗口內成立的增益，不模擬操作失誤、軸外
移動或脫戰增益。武器諧振、角色共鳴鏈、具名固有技能節點、合鳴件數及首位聲骸
均讀取已儲存資料。角色模態可逐隊指定；切換後會重新列出適用增益。

「直接延奏隊友」用來限制切換其他角色後消失的延奏，避免把兩位隊友的這類增益
同時疊加。全隊持續效果則仍可共存。同名武器、套裝的同一增益取較高值，不重複累加。
請核對增益清單中的觸發條件，不適用的效果取消勾選，再確認正常輪轉條件並儲存。
這個確認不會把缺漏的角色、武器、詞條或充能轉換資料變成已知。

常態面板與戰鬥面板分開顯示；比較不會覆寫量測面板。來源及不確定項目收在
「戰鬥數值」及強化頁的展開說明，主畫面只保留建議與各隊充能狀態。

## 充能

每隊的充能目標可依該隊正常輪轉設定；未填時使用角色的自訂目標或已查核攻略參考。
沒有參考時保持待補，不把100%當作已證實夠用。

充能只作可行性限制，超過需求不增加配裝指標。若角色的充能能轉換隊伍增益，
則目標至少包含該轉換的有效上限：守岸人250%、莫寧260%、穗穗260%戰鬥充能。
隊友提供的轉換依其實際裝備計算，不直接假設滿值；直接回能也不冒充充能百分比。

## 雙暴與配裝指標

聲骸原有品質分數、與原件分差、品質超越機率和素材成本仍保留。配裝比較另外
重算完整替換前後的角色數值、首位效果及合鳴效果，不把原件計入兩次。

模型 `combat-build.v1` 的一般雙暴期望基礎為 `1+p*(D-1)`，其中
`p=clamp(戰鬥暴率/100,0,1)`，`D=戰鬥暴傷/100`。低雙暴的相同資源比較以
暴率與額外暴傷1:2作平衡參考。配裝評分將暴率效益係數改為 `f(p)=p-p^9/9`，
採 `(1+f(p)*(D-1))*(1-0.15*(1-p)^2)` 作平滑取捨：低中暴率接近線性，
高暴率的新增效益逐漸飽和，98%到99%的額外得分低於相同資源增加2個百分點暴傷；
既有暴率不因接近100%倒扣。穩定性修正依連續未暴風險平滑淡出。100%以上暴率
完全不增加指標，暴傷不設上限。`f(p)`是效益分數係數，不是實際暴擊機率；
整個修正是產品偏好，不是官方傷害公式，也不保證等同實際傷害期望排序。

其他數值依角色有效評分設定的基礎權重，以生命、攻擊、防禦的對數效用，以及
所選輸出窗口的元素／傷害類型加成和加深比較。先滿足所有隊伍的充能，再由主要隊伍
決定輸出排序；主隊持平時，可接受其他隊提升且沒有隊伍下降的方案。次隊逐一
保留改善／下降差異。**配裝指標差不是實際傷害百分比或完整隊伍DPS**；技能倍率、
固定暴擊的獨立傷害、敵方抗性及防禦等不混入一般面板數值。技能專屬效果只能在
其適用的主要輸出窗口勾選，不能據此宣稱整條輪轉每段都享有同樣加成。
守岸人的洞悉解放傷害窗口另按必定暴擊處理，該窗口增加暴率不會增加指標；
六鏈洞悉、愛彌斯一鏈重擊及其他指定技能的暴傷也只在相應窗口使用。

## 培養與連動替換

- 已設定替換目標時比較完整配裝；自動角色模式辨識到已裝備的同一顆聲骸時，也
  提供自身強化的戰鬥參考，保留聲骸身份判斷。
- +15、+20另列剩餘副詞條使「所有隊伍充能達標且主隊指標提升」的聯合機率。
  依版本化公開調諧種類／數值分布精確枚舉，不把兩個機率相乘；主詞條固定在
  本次已辨識值，明確標示為剩餘副詞條預測。+15前沿用原本探索與品質預測，
  不捏造尚未確認的戰鬥完成機率。
- 候選很好但會缺充能時，保留為新配裝核心，從其他四個位置尋找連動方案。
  只使用本資料集有已確認觀測、未封存、未消耗且未占用其他位置的真實庫存。
  每個方案都重新計算全套，必須讓所有隊伍達標，並修復原本不足的充能、提高主隊指標，
  或在主隊持平時改善其他隊且不使任何隊下降。
- 搜尋按缺口與收益兩種方向各保留32條路徑，能調整其餘一至四件，最多顯示三個
  不同方案。這是有界候選搜尋，不宣稱找到全域最優；沒找到時顯示補強目標，
  不把尚未取得的聲骸視作存在。方案只供查看，不會自動換裝或移走其他角色裝備。

## 資料與保存

`data/characters/combat-effects.v1.json` 保存公開詞條的數值事實、適用條件、來源網址、
查核日期及內容SHA-256。2026-10-21批次核對目前20位角色、17把武器、20套合鳴與
19種首位聲骸的相關來源；另核對六階共鳴鏈的常態數值，將已確認的清宵一鏈暴率、
琳奈四鏈攻擊與達妮婭一鏈暴傷列入常態面板。庫街區WIKI由玩家編輯，來源平台
不代表所有數值經官方認證；本次新增戰鬥模型亦不宣稱已完成全部配置的遊戲實測。

獨立隊伍以 `cultivation_goal.combat_teams` 保存，主隊為 `combat_primary_team`。
不改既有共享隊伍成員關係、裝備身份或歷史紀錄。舊資料未設定戰鬥隊伍時沿用
既有品質流程；移除全部戰鬥隊伍可停用該角色的戰鬥比較。
