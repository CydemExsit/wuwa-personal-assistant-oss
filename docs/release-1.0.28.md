# v1.0.28 — 夜色粉紫與無音區綜合推薦

整合原先分別進行的介面與養成規劃更新。保留已確認的夜色粉紫主題、寬視窗聲骸並排檢視、角色五件配裝摘要與延伸表格高度，並加入下列無音區推薦改進。介面細節見 [夜色粉紫設計](release-1.0.27.md)。

無音區推薦會同時考量受益角色、可改善的聲骸件數、角色與隊伍重要性、現有分數和角色定位, 並偏好兩種套裝都能有效補缺口的場域。

角色編輯中的「優先級」現在會實際影響無音區排序, 數字越小越優先。已編入優先隊伍的角色也會得到適度加權。同角色缺多件仍有價值, 但逐件遞減; 多個角色各有明確缺口時會取得有限的人數加成。已達標副輸出的微小改善不會僅靠人數就放大成急迫需求。

推薦列直接顯示受益人數與件數。「查看推薦理由與資料待確認項目」可查看各件缺口、重要性、遞減權重與排序貢獻。未知分數、尚未開滿、COST 4、治療主詞條已合格等原有判斷保留, 同角色跨隊與替代套裝不重複計件。

排序點是養成比較規則, 不代表傷害增幅、掉落機率或確定可取得的件數。完整計算方式見 [規劃資料與排序規則](planning-data.md)。

Windows 介面套件固定使用已驗證的 PySide6 6.11.1。此次全新環境安裝的 6.12.0 在完整及單獨介面測試結束時, 均重現 Qt 原生元件存取違規; 相同介面測試在 6.11.1 正常結束。固定版本也讓本機封裝與 CI 使用相同的介面執行環境。

介面測試會在主執行緒銷毀每項測試建立的視窗，並在同一執行緒回收循環參照，避免背景資料工作回收遺留視窗而造成 Qt 原生崩潰。停止紀錄測試也改為等待實際完成紀錄，再執行原有的隱私斷言。實際評分整合測試保留完整計算與資料斷言，並給予較慢測試主機合理的完成時間；即使斷言失敗，也會先停止背景工作再清理畫面。
