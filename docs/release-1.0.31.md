# v1.0.31 — 兌換碼與程式內通知

側欄新增「兌換碼」：程式啟動及開啟期間每 30 分鐘檢查公開來源，發現新碼時在視窗上方顯示提示。按「查看兌換碼」進入清單，再按每組旁的「複製」即可貼至遊戲。複製只寫入剪貼簿，不代表已兌換。

- 提供「立即更新」及自動檢查開關；偏好與已提醒過的碼保存在本機，重複更新或重開不重複提醒。「知道了」可收起提示。
- 兌換碼檢查只由主視窗啟動，關閉時停止計時器、忽略晚到結果並收尾工作。沒有兌換碼系統通知、排程或關閉後常駐服務。既有活動提醒保持獨立。
- 來源是鳴潮繁中官方網站中最近八篇相關公告，以及 Pocket Tactics 的公開可用／失效清單。每組可開啟來源；官方文章只接受明確標示的文字碼，不辨識圖片、不讀取社群登入內容。來源收錄可能延遲或不完整。
- 彙整站的「可用」不是兌換保證；官方舊碼標示有效性及期限待確認。來源列為失效的碼預設隱藏且停用複製；移出來源清單的碼可從歷史選項查看。沒有可靠期限時不捏造倒數。
- 公開 GET 不帶帳號、Cookie、授權或本機遊戲資料；官方主機白名單保持原樣，彙整站使用固定 HTTPS 網址並拒絕重新導向。回應有逾時及大小限制，不下載圖片或執行網頁腳本。
- 經驗證的兌換碼欄位以原子寫入存於 `cache/public-data/redeem-codes.json`，不保存文章 HTML。更新或單一來源失敗時保留快取並明確提示；失敗來源的快取不觸發新碼通知。
