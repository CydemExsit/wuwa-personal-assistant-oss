# v1.0.33 — 聲骸自身強化與高分候選機會

辨識到替換位置已裝備的同一顆聲骸時，依保存的聲骸 ID 改為「現有聲骸強化」，不再拿自己比較超越機率與分差。配裝符合、資料完整且已達角色及格門檻時，明確建議「升至 +25 並保留」。保存位置、切換目標後會重新判斷情境。

不同顆聲骸若雙方目前累積分均達角色及格門檻，且候選落後不超過10分（含同分），超越機率及平均正向提升的投入門檻各減半，給高品質候選更多機會。通過後建議下一節點；實際機率不變，仍不保證能替換。資料不確定、配裝不符、模型上限無法超越，以及低品質候選的原有保護均保留。

政策升版為 `decision-policy.v6.json`；角色權重、原始詞條及歷史決策保持原狀。詳見[評分方法](scoring-methodology.md#14-v1033-現有聲骸強化與高品質替換)。

成品：`dist/releases/1.0.33/WuwaPersonalAssistant/WuwaPersonalAssistant.exe`。關閉舊版後啟動，保留同層 `_internal` 資料夾。
